# MemDice

![Python](https://img.shields.io/badge/Python-3.10+-blue?style=flat-square)
![Aiogram](https://img.shields.io/badge/Aiogram-3.x-green?style=flat-square)

Игровой Telegram-бот с использованием игры в кубики и системой выигрышей в Telegram Stars.

## Что это за проект?

**MemDice** — это игровой бот для Telegram, который позволяет пользователям:

- 🎲 Бросать кубик и выигрывать Telegram Stars
- 👤 Просматривать свой профиль с балансом и статистикой игр
- ⭐️ Накапливать выигрыши на балансе
- ✈️ Выводить выигранные средства в виде подписок Telegram Premium

Бот использует официальные платежи Telegram Stars для приема оплаты и начисления выигрышей.

## Как это работает?

1. **Подписка на каналы** — Для использования бота необходимо подписаться на указанные каналы
2. **Оплата броска** — Пользователь оплачивает бросок кубика через Telegram Stars (3 звезды)
3. **Бросок кубика** — Бот отправляет анимацию кубика и определяет результат (от 1 до 6)
4. **Начисление выигрыша** — Выигрыш рассчитывается по формуле: `выпавшее_число × 1000` звезд
5. **Вывод средств** — Накопленные звезды можно обменять на подписки Telegram Premium

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/FLYXSE/MemDice.git
cd MemDice
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=your_bot_token_here
CHANNELS=@channel1,@channel2
```

**Как получить BOT_TOKEN:**

1. Откройте @BotFather в Telegram
2. Создайте нового бота командой `/newbot`
3. Следуйте инструкциям и получите токен
4. Включите платежи (/mybots -> выберите бота -> Payments -> Telegram Stars)

**Настройка каналов:**

Укажите через запятую каналы, на которые должны подписаться пользователи:
```
CHANNELS=@mychannel1,@mychannel2
```

### 5. Запуск бота

```bash
python bot.py
```

## Технические детали

### Архитектура

- **Aiogram 3.x** — Основной фреймворк для Telegram Bot API
- **SQLite (aiosqlite)** — Локальная база данных для хранения пользователей
- **FSM (Finite State Machine)** — Управление состояниями игры
- **Telegram Stars** — Криптовалюта Telegram для платежей

### База данных

Таблица `users` содержит:
- `user_id` — ID пользователя Telegram
- `username` — Имя пользователя
- `full_name` — Полное имя
- `balance` — Баланс звезд
- `total_games` — Количество сыгранных игр
- `is_subscribed` — Статус подписки на каналы

### Логика выигрыша

```
Выигрыш = Выпавшее число × 1000 звезд
```

Например:
- Выпало 1 → 1,000 звезд
- Выпало 6 → 6,000 звезд

### Вывод средств

- 1 подписка Telegram Premium на 6 месяцев = 2,500 звезд
- Пользователь вводит количество подписок
- Бот списывает звезды и отправляет подписки
